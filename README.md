# 🚀 3D Сайт-Портфолио Веб-Программиста

Современный интерактивный сайт-портфолио веб-разработчика с трехмерной WebGL-сценой на Three.js, киберпанк-стилизацией, интерактивным CLI-терминалом, звуковым синтезатором и эффектами глубины.

---

## ✨ Ключевые возможности

- 🎮 **Интерактивная 3D-сцена (Three.js)**:
  - Процедурная кибер-комната: футуристический рабочий стол, ультраширокий изогнутый монитор с живой печатью кода, вертикальный монитор с графиками и логами, системный блок с RGB-кулерами, парящее голографическое ядро и летающие кубы стека.
  - Реакция на движение курсора (3D параллакс) и возможность свободного вращения сцены мышью/тачем.
  - Кинематографичный перелет камеры при скролле между секциями.
  - Поле светящихся интерактивных частиц космоса.
- ⚡ **Высокая производительность (60 FPS)**:
  - Полностью процедурные модели без тяжелых внешних `.glb/.gltf` файлов — загружается мгновенно даже при слабом интернете.
  - Оптимизированный рендеринг и троттлинг обновления холстов.
- 🖥️ **Интерактивный Web-терминал**:
  - Поддерживает команды: `help`, `bio`, `skills`, `projects`, `contact`, `matrix` (пасхалка: цифровой дождь из «Матрицы»), `clear`.
  - Быстрые кнопки-чипы для мобильных устройств.
- 🎨 **Интерактивные 3D-Tilt карточки проектов**:
  - Объемный наклон за курсором мыши, модальные окна с архитектурными деталями, ссылки на репозиторий и демо.
  - Салют из конфетти при переходе к демо.
- 🔊 **Кибер-звуковой контроллер (Web Audio API)**:
  - Синтезированные sci-fi звуки кликов, наведений и успехов без внешних аудиофайлов.
  - Кнопка включения/выключения звука в навигационной панели.
- 📱 **100% Адаптивность**:
  - Корректное отображение на смартфонах, планшетах и 4K-мониторах.
  - Мобильное шторка-меню и адаптивные сетки.

---

## 🛠️ Стек технологий

- **3D движок**: [Three.js](https://threejs.org/)
- **Сборщик**: [Vite](https://vitejs.dev/)
- **Стилизация**: [Tailwind CSS](https://tailwindcss.com/)
- **Звук**: Web Audio API (чистый JavaScript синт)
- **Иконки и анимации**: SVG + CSS3 3D Transforms + Canvas Confetti

## 🚀 Быстрый запуск

### 1. Установка зависимостей (уже выполнена)
```powershell
npm.cmd install
```

### 2. Запуск локального сервера разработки
```powershell
npm.cmd run dev
```
Сайт откроется автоматически по адресу: [http://localhost:3000](http://localhost:3000)

### 3. Сборка для продакшена
```powershell
npm.cmd run build
```
Готовые оптимизированные файлы появятся в директории `dist/`.

## ✏️ Как персонализировать данные под себя

Все данные собраны в одном удобном файле:  
👉 **`src/data/portfolioData.js`**

Вы можете легко отредактировать:
1. **`personal`**: Имя, специализацию, ссылки на GitHub, Telegram, LinkedIn, email.
2. **`stats`**: Опыт, число завершенных проектов, ключевые показатели.
3. **`skillCategories`**: Ваши технологии (Frontend, Backend, 3D, DevOps) и проценты владения.
4. **`projects`**: Ваши реальные проекты, скриншоты, ссылки на репозитории и рабочие демо.
5. **`experience`**: Места работы и достижения.
6. **`terminalCommands`**: Тексты ответов встроенного терминала.

## 🌐 Бесплатный деплой в интернет

### Вариант 1: Vercel (Рекомендуется)
1. Установите Vercel CLI: `npm.cmd i -g vercel`
2. Запустите в папке проекта: `vercel`
3. Следуйте подсказкам в терминале.

### Вариант 2: GitHub Pages
1. В `vite.config.js` укажите `base: '/<имя-репозитория>/'`
2. Запустите `npm.cmd run build`
3. Опубликуйте содержимое папки `dist/` в ветку `gh-pages`.

### Вариант 3: Netlify
Перетащите папку `dist/` в окно [Netlify Drop](https://app.netlify.com/drop).
