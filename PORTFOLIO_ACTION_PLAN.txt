Текущий статус проекта:
• Полностью собранный 3D WebGL сайт-портфолио на Three.js с процедурными моделями и 60 FPS.
• 4 флагманских интерактивных проекта (Nexus, Spatial 3D, FinFlow, Synapse AI).
• Полная русскоязычная документация и технические паспорта по каждому проекту.
• Единая премиальная дизайн-система Mocha & Bronze (#080604, темный шоколад, бронза, янтарь).
• Успешная сборка `npm run build` за 2.5 секунды без единой ошибки.

Ниже представлен структурированный чек-лист и дорожная карта того, что нужно сделать,
чтобы запустить портфолио в интернет и выжимать из него максимальный отклик от HR,
Senior-разработчиков и клиентов.

ЭТАП 1. ЗАМЕНА ПЕРСОНАЛЬНЫХ ДАННЫХ И КОНТАКТОВ (1-2 ЧАСА)
--------------------------------------------------------------------------------

Сейчас в файле `src/data/portfolioData.js` настроены базовые значения.
Перед публикацией необходимо внести свои реальные ссылки:

[ ] 1.1. Telegram:
    Замените `https://t.me/whhyy_dev` на ваш реальный логин в Telegram, куда вам удобно
    получать предложения о работе и сообщения от клиентов.

[ ] 1.2. GitHub:
    Замените `https://github.com/whhyy` на ваш реальный профиль GitHub.
    Желательно, чтобы никнейм на GitHub совпадал с вашим брендом.

[ ] 1.3. Резюме (CV):
    - Сгенерируйте актуальное PDF-резюме в едином стиле с портфолио;
    - Положите файл в папку `public/cv.pdf`;
    - В `src/data/portfolioData.js` обновите `resumeLink: "/cv.pdf"` (кнопки в шапке/контактах
      будут мгновенно скачивать ваше резюме).

[ ] 1.4. Фотография / Аватар:
    - Положите свое качественное портретное фото в папку `public/avatar.jpg`
      (рекомендуется стиль: нейтральный/темный фон, контрастный свет);
    - В `portfolioData.js` замените ссылку на `avatar: "/avatar.jpg"`.

[ ] 1.5. Форма обратной связи (Contact Form):
    Сейчас отправка формы эмулируется с красивым toast-уведомлением.
    Чтобы сообщения реально приходили вам, есть 2 простых бесплатных решения:
    Вариант А (самый удобный): Подключить Telegram Bot API через 5 строчек fetch-запроса,
    чтобы каждое сообщение с формы мгновенно падало вам в личный Telegram.
    Вариант Б: Использовать бесплатный сервис Formspree (https://formspree.io) или EmailJS,
    указав свой Email в атрибуте формы `action`.

    - В каждый из них загрузить готовые паспорта `PROJECT_*.md` как `README.md`!

ЭТАП 3. ПОКУПКА ДОМЕНА И БЕСПЛАТНЫЙ ДЕПЛОЙ (1-2 ЧАСА)
--------------------------------------------------------------------------------

Чтобы сайт выглядел солидно и открывался по адресу `whhyy.dev`:

[ ] 3.1. Регистрация домена:
    - Проверьте доступность домена `whhyy.dev` на любом аккредитованном регистраторе
      (например, Porkbun, Namecheap, Reg.ru или Cloudflare Registrar);
    - Зона `.dev` стоит обычно около $12-14 в год и требует HTTPS по умолчанию (от Google Registry).
    - Альтернативы, если занят: `whhyy.io`, `whhyy.tech`, `whhyy.pro`.

[ ] 3.2. Бесплатный деплой на Vercel или Cloudflare Pages (Рекомендуется Vercel):
    1. Зайдите на https://vercel.com и авторизуйтесь через GitHub;
    2. Нажмите "Add New Project" и выберите ваш репозиторий портфолио;
    3. Build Command: `npm run build`;
    4. Output Directory: `dist`;
    5. Нажмите "Deploy". Через 40 секунд сайт будет доступен в интернете!
    6. В настройках Vercel (Settings -> Domains) добавьте ваш домен `whhyy.dev`
       и пропишите указанные DNS-записи (CNAME или A-запись) у регистратора домена.
    7. Vercel автоматически выпустит бесплатный SSL-сертификат.

[ ] 3.3. Настройка SPA/Multi-Page редиректов (`vercel.json`):
    Чтобы страницы демо `demos/nexus/`, `demos/spatial/` и т.д. открывались
    корректно при прямой вставке URL или перезагрузке страницы, в корне проекта
    рекомендуется положить файл `vercel.json`:
    ```json
    {
      "cleanUrls": true,
      "trailingSlash": false
    }
    ```
