1. КОНЦЕПЦИЯ И АРХИТЕКТУРА 3D-СЦЕНЫ
--------------------------------------------------------------------------------

Главный сайт-портфолио спроектирован как визитная карточка инженера уровня Senior / Tech Lead,
демонстрирующая глубокое понимание современной веб-графики, интерактивности, производительности
и вкуса в UI/UX дизайне.

1.1. Экосистема процедурных 3D-моделей (MinimalistScene.js):
Вместо скачивания мегабайтных полигональных сеток из сети все 3D-объекты генерируются
на лету из математических примитивов Three.js:
• Ультрабук разработчика (3D Ultrabook Laptop):
  - Корпус из матового анодированного алюминия цвета мокко;
  - Клавиатурный блок и трекпад с алмазной гранью;
  - Светящийся экран с динамически сгенерированной текстурой реального IDE-кода (App.tsx).
• Парящее окно браузера (Floating Glass Browser):
  - Матовое рифленое стекло (Translucent Frosted Glass);
  - Фирменные macOS точки управления (закрыть, свернуть, развернуть);
  - Строка безопасного URL (https://whhyy.dev) и карточки веб-лейаута.
• Серверный стек баз данных (Database Server Stack):
  - 3 металлических цилиндрических диска с бронзовой текстурой шлифовки;
  - Неоновые кольца активности данных (аквамарин и янтарь), непрерывно вращающиеся вокруг оси.
• Атом веб-технологий (React / Web Tech Gyro-Atom):
  - Центральное светящееся ядро;
  - 3 переплетенных орбитальных эллиптических кольца с вращающимися электронами данных.
• Световые лучи передачи данных (Data Flow Beams):
  - Пунктирные неоновые траектории, соединяющие Базу данных <-> Ноутбук <-> Браузер,
    символизирующие неразрывную Fullstack-архитектуру.

1.2. Процедурный листопад осенних листьев (AutumnLeaves.js):
• 95 трехмерных изогнутых листьев, рендерящихся всего за 1 вызов отрисовки (Draw Call)
  благодаря THREE.InstancedMesh.
• Палитра теплых осенних оттенков: терракота, жженый апельсин, каштан, медовое золото и медь.
• Физика аэродинамики:
  - Маятниковое покачивание (fluttering);
  - Кувыркание в трех плоскостях (3D tumbling);
  - Плавное завихрение при движении курсора мыши;
  - Бесшовный бесконечный цикл падения.

1.3. Кинематографическая камера (CameraController.js):
• Плавное панорамирование и интерполяция ракурса камеры (lerp) при скролле между секциями:
  Hero -> About -> Skills -> Projects -> Terminal -> Contact.
• Адаптивная расстановка объектов для смартфонов, планшетов и 4K-мониторов.

4. ВОПРОСЫ И ОТВЕТЫ ДЛЯ ТЕХНИЧЕСКИХ СОБЕСЕДОВАНИЙ
--------------------------------------------------------------------------------

В: "Как удалось добиться 60 FPS при наличии 95 падающих листьев и сложных 3D-моделей?"
О: "Ключевая оптимизация — использование THREE.InstancedMesh. Вместо создания 95 отдельных
    объектов с индивидуальными вызовами отрисовки (Draw Calls), все листья объединяются
    в одну инстанцированную сетку. Их координаты, вращение и фазы маятникового качания
    обновляются за один проход в цикле requestAnimationFrame через матрицы трансформации
    (Matrix4), что минимизирует нагрузку на шину CPU-GPU."

В: "Как устроена адаптивность камеры и сцены при изменении размера экрана?"
О: "Используется контроллер CameraController, слушающий событие resize с троттлингом.
    Камера PerspectiveCamera динамически пересчитывает aspect ratio и вертикальный угол
    обзора (FOV): на мобильных устройствах камера плавно отодвигается по оси Z,
    чтобы ключевые объекты сцены оставались строго в фокусе внимания пользователя."

В: "Почему звуки генерируются программно, а не загружаются в виде MP3?"
О: "Процедурная генерация на Web Audio API дает 3 ключевых преимущества:
    1. Нулевой сетевой оверхед (экономия мегабайт трафика);
    2. Мгновенный отклик без задержек на буферизацию (ноль миллисекунд latency);
    3. Динамическая модуляция частоты и тональности в зависимости от контекста взаимодействия."
