1. КОНЦЕПЦИЯ И БИЗНЕС-НАЗНАЧЕНИЕ ПРОЕКТА
--------------------------------------------------------------------------------

FinFlow — это интерактивная финтех-платформа премиум-класса для консолидированного
учета капитала, мониторинга инвестиционных портфелей, аналитики распределения активов
и проведения защищенных мультивалютных транзакций.

Бизнес-задачи, которые решает проект:
1. Сквозной учет капитала (Unified Wealth Tracking):
   Объединение всех активов владельца в едином окне:
   - Ликвидный фиат (USD, EUR, GBP);
   - Высокодоходные сберегательные инструменты (High-Yield Cash 5.15% APY);
   - Цифровые активы и стейкинг (Bitcoin Vault, Ethereum Staking, Solana);
   - Фондовый рынок (индексные ETF S&P 500, дивидендные акции, фонды недвижимости REITs).

2. Мгновенная мультивалютная конвертация:
   Позволяет в один клик переключать базовую валюту отображения всего портфеля
   (USD $, EUR €, GBP £) с автоматическим синхронным пересчетом всех балансов,
   осей графика, секторов круговой диаграммы и записей в реестре.

3. Безопасность институционального уровня (Bank-Grade Zero-Trust Security):
   Имитация сквозной криптографической сессии (AES-GCM-256, ECDH P-384, SHA3-512),
   живой 15-минутный таймер ротации одноразовых токенов и интерактивный терминал
   генерации новых криптографических ключей.

4. Интерактивные переводы и нулевой клиринг:
   Модуль отправки средств с быстрыми пресетами суммы, живым расчетом эквивалента
   в других валютах и мгновенным занесением проводки в распределенный реестр.

2. ТЕХНОЛОГИЧЕСКИЙ СТЕК И АРХИТЕКТУРА
--------------------------------------------------------------------------------

2.1. Frontend Architecture:
• Полноэкранная адаптивная сетка (Full-Bleed CSS Grid):
  - Контейнер .finflow-container растягивается на 100% ширины экрана;
  - Левая колонка занимает всё свободное пространство экрана: minmax(0, 1fr);
  - Правая колонка плавно масштабируется по ширине (380px -> 420px -> 460px);
  - Защита min-w-0 от горизонтального скролла на любых дисплеях.
• Дизайн-система Mocha & Bronze Glassmorphism:
  - Глубокий темно-шоколадный фон (#0a0705);
  - Полупрозрачные стеклянные карточки с размытием (backdrop-filter: blur(20px));
  - Границы из теплой бронзы и золота (rgba(224, 169, 109, 0.12));
  - Акцентные неоновые цвета: янтарь (#f59e0b), изумруд (#10b981), бирюза (#06b6d4), аметист (#a855f7).
• Native Canvas 2D API (без Chart.js / Highcharts):
  - Рендеринг кривых Безье, многослойных градиентов и круговых диаграмм;
  - Поддержка Retina/HiDPI через window.devicePixelRatio;
  - Реакция на изменение размера через современный ResizeObserver.

2.2. Backend & Data Layer (Архитектура в Production):
• API Gateway & Микросервисы: NestJS (TypeScript) с модульной структурой (Auth, Wallets, FX-Rates, Ledger).
• База данных: PostgreSQL с поддержкой строгой ACID-целостности финансовых транзакций.
• In-Memory слой: Redis Cluster для мгновенного кэширования валютных курсов и Pub/Sub брокер тиков.
• Контейнеризация: Docker & Kubernetes для изолированного отказоустойчивого развертывания.

  - Подтверждения в распределенной сети («64/64 Finalized»);

• Кнопка «+ Inbound $5K»:
  Мгновенное пополнение резервов на $5,000.00 с салютом конфетти, пересчетом баланса
  и занесением новой проводки во главу журнала.
• Фильтрация по категориям: All, Transfers, Crypto, Dividends.
• Живой мгновенный поиск по контрагенту, ID транзакции или типу актива.

3.6. Круговая диаграмма распределения активов (Asset Allocation Donut):

  Каждые 2.2 секунды котировки обновляются, строка вспыхивает зеленым при росте

3.8. Кинематографичный терминал ротации ключей (Security Engine):
• Параметры защиты: AES-GCM-256, ECDH P-384, узел Zurich Node #12, Zero-Trust.
• Анимированная симуляция ротации по нажатию кнопки «Rotate Cryptographic Keys ↻»:
  1. [1/4] Destroying ephemeral session 0x8F9B... (25%)
  2. [2/4] Generating 512-bit CSPRNG seed... (55%)
  3. [3/4] Mutual HMAC verification with Zurich Enclave... (85%)
  4. [4/4] AES-GCM-256 cipher updated. Zero-trust valid. (100%)
• Сопровождается неоновым градиентным прогресс-баром, салютом золотых конфетти
  и сбросом сессионного таймера на 15:00.

3.9. Модуль перевода средств (Transfer Modal):
• Пресеты быстрого ввода суммы: +$100, +$500, +$2.5K, MAX.
• Живой FX-калькулятор: при вводе суммы сразу отображается расчетный эквивалент
  в других валютах (например, «≈ €460.00 / 0.0078 BTC»).
• Салют конфетти и мгновенное добавление транзакции в реестр со статусом «Just now».

3.10. Всплывающая система уведомлений (Toast System):

4. ОПТИМИЗАЦИИ ПРОИЗВОДИТЕЛЬНОСТИ И НАДЕЖНОСТИ
--------------------------------------------------------------------------------

1. Легковесный нативный Canvas 2D:
   Отказ от тяжелых библиотек позволил сэкономить более 250 КБ трафика и достичь
   стабильных 60 кадров в секунду даже на мобильных процессорах.
2. Retina & HiDPI поддержка:
   Все холсты автоматически масштабируются с учетом window.devicePixelRatio, исключая
   размытие текста и линий на экранах высокой четкости (Apple Retina, 4K мониторы).
3. Адаптивность через ResizeObserver:
   Автоматический мгновенный пересчет физических координат без артефактов растяжения.
4. CSS Grid minmax(0, 1fr):
   Гарантирует 100% заполнение экрана без пустых черных областей справа и без переполнения.

6. ПОШАГОВЫЙ СЦЕНАРИЙ ПРЕЗЕНТАЦИИ НА СОБЕСЕДОВАНИИ
--------------------------------------------------------------------------------

Шаг 1: Позиционирование проекта:
«FinFlow — это высокопроизводительная финтех-платформа для управления частным капиталом.
Она сочетает в себе работу с комплексными аналитическими дашбордами, мультивалютными
расчетами, нативной Canvas-графикой и строгими протоколами безопасности банковского уровня.»

Шаг 2: Демонстрация мультивалютности:
В верхней панели переключите валюту с USD на EUR и GBP. Обратите внимание собеседника
на то, как одновременно и синхронно пересчитались все 4 карточки капитала, ось графика
доходности, диаграмма аллокации и реестр транзакций.

Шаг 3: График доходности и бенчмарки:
- Включите кнопки бенчмарков «S&P 500» и «BTC» — покажите наложение пунктирных линий.
- Покажите пульсирующий радарный маяк на конце линии и режим «Live Pulse ⚡».
- Нажмите «Snapshot 📸» для мгновенной генерации PNG-отчета.
- Проведите мышью по графику, показав лазерный инспектор котировок.

Шаг 4: Кросс-фильтрация и спарклайны:
- Нажмите на карточку «Digital Assets» или сектор «Crypto» на круговой диаграмме:
  покажите, как таблица транзакций слева мгновенно отфильтровалась только по криптоактивам.
- Кликните по любой транзакции, чтобы развернуть криптографический блок доказательств,
  и нажмите кнопку «Copy» для копирования хеша в буфер.

Шаг 5: Переводы и мгновенный депозит:
- Нажмите «+ Inbound $5K» для моментального пополнения баланса с конфетти.
- Откройте модальное окно «Transfer ↗», выберите пресет «+$500», покажите живой FX-расчет
  и отправьте средства: продемонстрируйте салют и добавление новой проводки в начало журнала.

Шаг 6: Кинематографичная безопасность:
В блоке Security Engine нажмите «Rotate Cryptographic Keys ↻». Продемонстрируйте
интервьюеру пошаговый консольный лог генерации криптографической энтропии, прогресс-бар
и сброс сессионного таймера.
